# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The NeoNotion team takes the security of our software and user data sovereignty seriously.

If you believe you have discovered a vulnerability in NeoNotion or Neo OS:

1. **Do not disclose it publicly** via GitHub issues, discussion forums, or social media.
2. Email the details directly to **[itispourya@gmail.com](mailto:itispourya@gmail.com)** with the subject line: `[SECURITY] NeoNotion Vulnerability Report`.
3. Provide a detailed summary, including:
   - Type of issue (e.g. CSRF, XSS, injection, data exposure)
   - Step-by-step instructions or proof-of-concept to reproduce the vulnerability
   - Potential impact on users or organizations
   - Any suggested mitigations or patches

### Response SLA
- **Initial Response**: Within 48 hours acknowledging receipt of your report.
- **Assessment & Triage**: Within 5 business days with an evaluation of the severity.
- **Fix & Disclosure**: Coordinated disclosure after a patch has been published.

Thank you for helping keep NeoNotion and our community secure.
